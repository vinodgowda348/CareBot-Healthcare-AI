# W5D2 - Ollama Model Comparison

## Models Tested

- llama3.2:3b
- qwen2.5:3b

## Test Method

Both models were tested locally using Ollama.

The same three questions and the same system prompt were used for both models.

System prompt:

> Answer clearly, accurately, and concisely. Do not invent information.

## Questions Tested

1. What is a clinical note?
2. What is the difference between symptoms and diagnosis?
3. Why is follow-up information important in healthcare?

## Comparison

### Question 1

Llama 3.2:3B provided a more detailed and structured explanation.

Qwen 2.5:3B provided a shorter and more concise explanation.

### Question 2

Both models clearly explained the difference between symptoms and diagnosis.

Llama 3.2:3B provided more explanation, while Qwen 2.5:3B was more concise.

### Question 3

Both models explained the importance of monitoring patient progress, adjusting treatment, and identifying problems early.

Llama 3.2:3B used a more structured response, while Qwen 2.5:3B gave a concise paragraph.

## Overall Observation

Both local models successfully answered all three questions.

Llama 3.2:3B generally produced more detailed and structured responses in this test.

Qwen 2.5:3B generally produced shorter and more concise responses.

This comparison is based only on the three questions tested and is not a comprehensive benchmark.

## Conclusion

Both models can be used for local experimentation with prompt engineering and system prompts. The test demonstrated how changing the model can affect response length, structure, and level of detail while keeping the questions and system prompt consistent.
